# Agent10 Project Brain

## Principles
1. **Maintain long-term vision**: Keep the ultimate project goals in mind and align code changes with them.
2. **Consult Architecture & Decisions First**: Read existing architecture guides, maps, and decisions before making changes.
3. **Task & Backlog Management**: Keep track of the roadmap, backlog items, risks, and next actions.
4. **Document Key Decisions**: Create artifacts or logs for any important architectural or design choices.
5. **Update State**: Document and update the project status/state after completing tasks.
